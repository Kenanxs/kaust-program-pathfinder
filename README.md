# KAUST Program Pathfinder

A yes/no guide that helps anyone, including people with no prior knowledge of KAUST, find the KAUST innovation programs and teams that fit them. Many people match more than one.

**Live page:** https://kenanxs.github.io/kaust-program-pathfinder/

## Updating program details
All program text, eligibility questions and links live in `index.html`, in the `P` (programs) and `Q` (questions) objects near the bottom of the file. Edit them and commit to `main`; GitHub Pages republishes automatically within a few minutes.

Maintained by the EC Portfolio Team. Program details come from public KAUST program pages (November 2026); each program confirms eligibility when people apply.
